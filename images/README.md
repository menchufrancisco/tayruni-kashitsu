# Carpeta de Imágenes (`images/`)

Guarda aquí las imágenes de tu portafolio para que se muestren en el sitio web:

- **Foto Principal / Hero**: Guarda tu foto como `images/hero.jpg` y añádela dentro de `<div class="hero-photo">` en `index.html`:
  ```html
  <div class="hero-photo">
    <img src="images/hero.jpg" alt="Tayruni Kashitsu Cosplay">
  </div>
  ```

- **Retrato / Sobre Mí**: Guarda tu foto como `images/sobre-mi.jpg` y añádela en `<div class="portrait">`:
  ```html
  <div class="portrait">
    <img src="images/sobre-mi.jpg" alt="Retrato Tayruni Kashitsu">
  </div>
  ```

- **Tarjetas de Cosplay**: Guarda fotos como `images/cosplay-1.jpg`, `images/cosplay-2.jpg`, etc., y agrégalas dentro de cada `<article class="card">`:
  ```html
  <article class="card">
    <img src="images/cosplay-1.jpg" alt="Cosplay de Jinx">
    <div class="label">
      <strong>Jinx</strong>
      <small>LEAGUE OF LEGENDS</small>
    </div>
  </article>
  ```

- **Proyecto Destacado**: Guarda tu foto como `images/destacado.jpg` y añádela en `<div class="feature-photo">`:
  ```html
  <div class="feature-photo">
    <img src="images/destacado.jpg" alt="Jinx Cosplay Destacado">
  </div>
  ```

*Nota: Mientras no se agreguen imágenes, el diseño mantiene automáticamente los recuadros estilizados y etiquetas visuales idénticos al diseño original de Canva.*
